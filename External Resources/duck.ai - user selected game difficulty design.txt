# Implementing Game Difficulty in Your Unity Top-Down Shooter

**Create a centralized difficulty system using a ScriptableObject to define difficulty settings, then use a GameManager singleton to access and apply these settings across scenes.** This approach keeps your difficulty data organized and makes it easy to modify without changing code.

---

## Architecture Overview

Here's the recommended structure:

| Component | Purpose | Example |
|-----------|---------|---------|
| **DifficultySettings (ScriptableObject)** | Defines all difficulty parameters (HP, enemy count, etc.) | Easy: 100 HP, 3 enemies; Hard: 50 HP, 8 enemies |
| **GameManager (Singleton)** | Persists across scenes, holds current difficulty reference, applies settings | Loads DifficultySettings, spawns enemies based on difficulty |
| **MainMenu Scene** | UI for difficulty selection | Buttons for Easy/Medium/Hard that set GameManager's current difficulty |
| **Level Scenes** | Actual gameplay | Enemy spawners and player read from GameManager |

# Two-Manager Architecture with Communication

**Use a singleton pattern for both managers where MainManager persists across scenes and GameManager reads the difficulty settings from MainManager when the level loads.** MainManager acts as a data holder, while GameManager consumes that data to configure the game.

---

## Architecture Overview

| Manager | Purpose | Lifespan |
|---------|---------|----------|
| **MainManager** | Stores selected difficulty, persists across scenes, loads appropriate level | Persists from Main Menu through all levels |
| **GameManager** | Reads difficulty from MainManager, spawns enemies, sets HP values, manages gameplay loop | Created fresh in each level scene |

```csharp
using UnityEngine.SceneManagement;

public class MainManager : MonoBehaviour
{
    public static MainManager Instance { get; private set; }

    /// GameManager will call this to get the selected difficulty
    /// </summary>
    public DifficultySettings GetSelectedDifficulty()
    {
        if (selectedDifficulty == null)
        {
            Debug.LogWarning("MainManager: No difficulty selected! Returning default.");
            return Resources.Load<DifficultySettings>("Difficulties/Easy"); // Fallback
        }
        return selectedDifficulty;

    /// Load a level scene

        SceneManager.LoadScene(levelSceneName);
    }
    
    /// <summary>
    /// Return to main menu (optional, for later use)
    /// </summary>
    public void ReturnToMainMenu()
    {
```

## Step 2: Create GameManager Script

**Create `GameManager.cs` (placed in each level scene as a fresh instance):**

```csharp
using UnityEngine;

public class GameManager : MonoBehaviour
{
    public static GameManager Instance { get; private set; }
    
    private DifficultySettings currentDifficulty;
    
    [SerializeField] private GameObject enemyPrefab;
    [SerializeField] private Transform[] enemySpawnPoints;
    [SerializeField] private Player playerScript;
    
    private int enemiesAlive;
    
    private void Awake()
    {
        // Singleton for this level only (destroyed when scene changes)
        if (Instance != null && Instance != this)
        {
            Destroy(gameObject);
            return;
        }
        
        Instance = this;
    }
    
    private void Start()
    {
        // Get difficulty settings from MainManager
        currentDifficulty = MainManager.Instance.GetSelectedDifficulty();
        Debug.Log($"GameManager: Received difficulty - {currentDifficulty.difficultyName}");
        
        // Initialize player with difficulty settings
        InitializePlayer();
        
        // Spawn enemies based on difficulty
        SpawnEnemies();
    }
    
    /// <summary>
    /// Initialize player with difficulty settings
    /// </summary>
    private void InitializePlayer()
    {
        if (playerScript != null)
        {
            playerScript.Initialize(currentDifficulty);
            Debug.Log($"GameManager: Player initialized with {currentDifficulty.playerMaxHP} HP");
        }
        else
        {
            Debug.LogError("GameManager: Player script not assigned!");
        }
    }
    
    /// <summary>
    /// Spawn enemies based on difficulty settings
    /// </summary>
    private void SpawnEnemies()
    {
        enemiesAlive = currentDifficulty.enemyCount;
        
        for (int i = 0; i < currentDifficulty.enemyCount; i++)
        {
            // Cycle through spawn points if there are fewer spawn points than enemies
            Transform spawnPoint = enemySpawnPoints[i % enemySpawnPoints.Length];
            
            GameObject enemyObject = Instantiate(enemyPrefab, spawnPoint.position, Quaternion.identity);
            Enemy enemyScript = enemyObject.GetComponent<Enemy>();
            
            if (enemyScript != null)
            {
                enemyScript.Initialize(currentDifficulty, this);
                Debug.Log($"GameManager: Enemy {i + 1} spawned with {currentDifficulty.enemyMaxHP} HP");
            }
        }
    }
    
    /// <summary>
    /// Called by enemies when they die
    /// </summary>
    public void EnemyDefeated()
    {
        enemiesAlive--;
        Debug.Log($"GameManager: Enemy defeated. Enemies remaining: {enemiesAlive}");
        
        if (enemiesAlive <= 0)
        {
            LevelComplete();
        }
    }
    
    /// <summary>
    /// Called when all enemies are defeated
    /// </summary>
    private void LevelComplete()
    {
        Debug.Log("GameManager: Level Complete!");
        // Add your level complete logic here (UI, next level, etc.)
    }
    
    /// <summary>
    /// Getter for current difficulty (if other scripts need it)
    /// </summary>
    public DifficultySettings GetDifficulty()
    {
        return currentDifficulty;
    }
}
```

# MainManager Persistence and Main Menu Reloading

**When you reload the Main Menu scene, MainManager won't be destroyed because of `DontDestroyOnLoad()`, so you'll have the old instance still active in the scene.** This creates a problem: you'll have duplicate managers or unexpected behavior.

---

## The Problem

When the user quits to Main Menu:

```
User in Level1 → Quits to Main Menu
    ↓
SceneManager.LoadScene("MainMenu")
    ↓
MainManager already exists (DontDestroyOnLoad prevented destruction)
    ↓
New Main Menu scene loads
    ↓
Now you have OLD MainManager in the scene + NEW Main Menu UI
    ↓
Potentially confusing state or duplicate managers
```

---

## Solution: Reload MainManager When Returning to Main Menu

**Modify `MainManager.cs` to detect when the Main Menu scene loads and reset itself:**

```csharp
using UnityEngine;
using UnityEngine.SceneManagement;

public class MainManager : MonoBehaviour
{
    public static MainManager Instance { get; private set; }
    
    [SerializeField] private DifficultySettings selectedDifficulty;
    [SerializeField] private string mainMenuSceneName = "MainMenu"; // Set in Inspector
    
    private void Awake()
    {
        // Singleton pattern
        if (Instance != null && Instance != this)
        {
            Destroy(gameObject);
            return;
        }
        
        Instance = this;
        DontDestroyOnLoad(gameObject);
    }
    
    private void OnEnable()
    {
        // Subscribe to scene load events
        SceneManager.sceneLoaded += OnSceneLoaded;
    }
    
    private void OnDisable()
    {
        // Unsubscribe to avoid memory leaks
        SceneManager.sceneLoaded -= OnSceneLoaded;
    }
    
    /// <summary>
    /// Called whenever a scene loads
    /// </summary>
    private void OnSceneLoaded(Scene scene, LoadSceneMode mode)
    {
        // If Main Menu scene is loaded, reset the difficulty
        if (scene.name == mainMenuSceneName)
        {
            ResetDifficulty();
            Debug.Log("MainManager: Returned to Main Menu. Difficulty reset.");
        }
    }
    
    /// <summary>
    /// Reset difficulty when returning to main menu
    /// </summary>
    private void ResetDifficulty()
    {
        selectedDifficulty = null;
    }
    
    public void SelectDifficulty(DifficultySettings difficulty)
    {
        selectedDifficulty = difficulty;
        Debug.Log($"MainManager: Difficulty selected - {difficulty.difficultyName}");
    }
    
    public DifficultySettings GetSelectedDifficulty()
    {
        if (selectedDifficulty == null)
        {
            Debug.LogWarning("MainManager: No difficulty selected! Returning default.");
            return Resources.Load<DifficultySettings>("Difficulties/Easy");
        }
        return selectedDifficulty;
    }
    
    public void LoadLevel(string levelSceneName)
    {
        Debug.Log($"MainManager: Loading level - {levelSceneName}");
        SceneManager.LoadScene(levelSceneName);
    }
    
    public void ReturnToMainMenu()
    {
        Time.timeScale = 1f; // Unpause if paused
        SceneManager.LoadScene(mainMenuSceneName);
    }
}
```

# Return Statement and First-Time Initialization

**Good questions! Let's break both down:**

---

## Do You Need the `return` Statement?

**Yes, you should keep the `return`.** Here's why:

```csharp
if (Instance != null && Instance != this)
{
    Destroy(gameObject);
    return;  // ← Important!
}
```

**Without `return`:** After `Destroy(gameObject)` is called, the rest of Awake() continues executing on the destroyed object:

```csharp
if (Instance != null && Instance != this)
{
    Destroy(gameObject);
    // WITHOUT return, code continues here...
}

Instance = this;  // ← This still runs on the destroyed object!
DontDestroyOnLoad(gameObject); // ← This still runs too!
```

This means you're setting `Instance = this` (the new, destroyed instance) **after** destroying it, which overwrites the old instance reference. **This breaks the singleton.**

**With `return`:** The method exits immediately, so the problematic code doesn't run.

```csharp
if (Instance != null && Instance != this)
{
    Destroy(gameObject);
    return;  // ← Exits Awake() here, rest doesn't execute
}

Instance = this;  // ← Only runs for the FIRST instance
DontDestroyOnLoad(gameObject); // ← Only runs for the FIRST instance
```

---

## Only Set DontDestroyOnLoad the First Time

**Yes, you can optimize this!** Since you only need `DontDestroyOnLoad()` once (on the original instance), you could move it outside the conditional:

```csharp
private void Awake()
{
    if (Instance != null && Instance != this)
    {
        Destroy(gameObject);
        return;
    }
    
    Instance = this;
    DontDestroyOnLoad(gameObject);
}
```

This is exactly what you already have. **The `DontDestroyOnLoad()` only runs on the first instance** because:
- **First instance:** `Instance == null`, so it skips the if block, runs `DontDestroyOnLoad()`
- **Duplicate instances:** `Instance != null`, so they're destroyed before reaching `DontDestroyOnLoad()`

So your current code is already optimized! You don't need any changes.

---

## Alternative: Make It Even More Explicit

If you want to be extra clear that this only happens once, you could write it like:

```csharp
private void Awake()
{
    if (Instance == null)
    {
        // First time — initialize
        Instance = this;
        DontDestroyOnLoad(gameObject);
    }
    else if (Instance != this)
    {
        // Duplicate found — destroy it
        Destroy(gameObject);
    }
}
```

This reads more intuitively: "If there's no instance, create one. If there is one and it's not me, destroy me."

But **your original version is functionally identical and perfectly fine.** It's a matter of readability preference.

## How to Refactor

**Remove the singleton pattern from GameManager:**

```csharp
public class GameManager : MonoBehaviour
{
    [SerializeField] private GameObject enemyPrefab;
    [SerializeField] private Transform spawnPoint;
    
    private DifficultySettings currentDifficulty;
    private Player player;

    private void Start()
    {
        // Get difficulty from MainManager
        currentDifficulty = MainManager.Instance.GetSelectedDifficulty();
        
        // Initialize player and spawn enemies
        InitializePlayer();
        SpawnEnemies();
    }

    private void InitializePlayer()
    {
        // Find player in scene and initialize it
        player = FindObjectOfType<Player>();
        if (player != null)
        {
            player.Initialize(currentDifficulty);
        }
    }

    private void SpawnEnemies()
    {
        for (int i = 0; i < currentDifficulty.enemyCount; i++)
        {
            GameObject enemyObj = Instantiate(enemyPrefab, spawnPoint.position, Quaternion.identity);
            Enemy enemy = enemyObj.GetComponent<Enemy>();
            if (enemy != null)
            {
                enemy.Initialize(currentDifficulty, this);
            }
        }
    }
}
```
