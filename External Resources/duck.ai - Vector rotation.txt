newX = x * cos(angle) - y * sin(angle)

## What Are Radians?

**Radians and degrees are just two different ways to measure angles.**

- **Degrees:** A full circle = 360°
- **Radians:** A full circle = 2π (about 6.28)

They measure the same thing, just with different units. It's like meters vs feet—same distance, different scale.

**Why radians?** Sine and cosine work with radians, not degrees. That's why we convert:

```csharp
float rad = angle * Mathf.Deg2Rad;  // Convert 45° to radians
```

`Mathf.Deg2Rad` is just a constant that equals π/180, which does the conversion math for you.

---

## Understanding Sine and Cosine

**Sine and cosine come from a circle.** Imagine a unit circle (radius = 1) centered at origin (0,0).

If you pick any angle on that circle:
- **Cosine(angle)** = the X coordinate of that point
- **Sine(angle)** = the Y coordinate of that point

For example:
- At 0°: `cos(0°) = 1, sin(0°) = 0` → point is at (1, 0) — right side
- At 90°: `cos(90°) = 0, sin(90°) = 1` → point is at (0, 1) — top
- At 45°: `cos(45°) ≈ 0.707, sin(45°) ≈ 0.707` → point is at (0.707, 0.707) — diagonal

---

## Now the Rotation Formula

Let's say you have a vector **(x, y)** and want to rotate it by some angle.

**The key insight:** When you rotate a vector, you're rotating it around the origin (0,0). The new position must be on a circle centered at the origin.

The formula combines two things:

```csharp
newX = x * cos(angle) - y * sin(angle)
newY = x * sin(angle) + y * cos(angle)
```

### Breaking it down:

**For newX:**
- `x * cos(angle)` — This is the x-component rotated
- `- y * sin(angle)` — This subtracts the y-component's rotated influence (the minus is crucial for the direction to be correct)

**For newY:**
- `x * sin(angle)` — This is the x-component's rotated influence on the y-axis
- `+ y * cos(angle)` — This is the y-component rotated

---

## A Real Example: Rotating (1, 0) by 45°

Original vector: **(1, 0)** (pointing right)

**Step 1:** Convert 45° to radians
```
radians = 45 * π/180 ≈ 0.785
```

**Step 2:** Calculate sine and cosine
```
cos(45°) ≈ 0.707
sin(45°) ≈ 0.707
```

**Step 3:** Apply the formula
```
newX = 1 * 0.707 - 0 * 0.707 = 0.707
newY = 1 * 0.707 + 0 * 0.707 = 0.707
```

Result: **(0.707, 0.707)** — pointing diagonally up-right at 45°! ✓

---

## Another Example: Rotating (0, 1) by 90°

Original vector: **(0, 1)** (pointing up)

```
cos(90°) = 0
sin(90°) = 1
```

```
newX = 0 * 0 - 1 * 1 = -1
newY = 0 * 1 + 1 * 0 = 0
```

Result: **(-1, 0)** — pointing left! That's a 90° counter-clockwise rotation. ✓

---

## Why Does This Work?

The formula is derived from the **rotation matrix**, which is a mathematical operation that rotates coordinates. The sine and cosine values ensure that:
1. The vector's **length stays the same** (no stretching)
2. The **angle increases correctly**
3. The rotation happens in the **right direction**

So when you write that formula, you're literally applying a mathematical rule that's guaranteed to rotate your vector correctly. It's not magic—it's proven geometry!
